# 第 11 周：Redis 缓存

## 一、Redis 是什么
- 内存数据库，读写速度快
- Key-Value 存储
- 常用于缓存、会话、消息队列 broker

## 二、常用数据类型

| 类型 | 示例 | 用途 |
|------|------|------|
| String | `set key value` | 简单缓存、计数器 |
| Hash | `hset user:1 name zhangsan` | 对象字段 |
| List | `lpush queue task` | 队列 |
| Set | `sadd tags python` | 去重、交集 |
| ZSet | `zadd rank 90 user1` | 排行榜 |

## 三、缓存模式 Cache Aside
```text
读请求：
1. 查 Redis
2. 命中 -> 直接返回
3. 未命中 -> 查 MySQL
4. 写入 Redis（带过期时间）
5. 返回结果

写请求：
1. 更新 MySQL
2. 删除 Redis 缓存
```

项目中的示例：
```python
cache_key = "items:list"
cached = redis_client.get(cache_key)
if cached is not None:
    return json.loads(cached)

items = db.query(Item).all()
redis_client.setex(cache_key, 60, json.dumps(jsonable_encoder(items)))
return items
```

## 四、项目接入

### 1. docker-compose.yml 增加 Redis
```yaml
redis:
  image: redis:7
  restart: unless-stopped
  ports:
    - "6379:6379"
  healthcheck:
    test: ["CMD", "redis-cli", "ping"]
    interval: 5s
    timeout: 5s
    retries: 10
```

### 2. 配置 REDIS_URL
```python
REDIS_URL = os.getenv("REDIS_URL", "redis://localhost:6379/0")
```

Docker 环境中：
```text
REDIS_URL=redis://redis:6379/0
```

### 3. Redis 客户端
```python
import redis

redis_client = redis.Redis.from_url(REDIS_URL, decode_responses=True)
```

### 4. 缓存接口
```text
GET /items/cached
```
- 先查 Redis
- 未命中再查 MySQL
- 结果写入 Redis，TTL 60 秒

### 5. 分页缓存与失效
`GET /items` 也接入了分页缓存：

```python
cache_key = f"items:list:{pagination.page}:{pagination.size}"
```

商品创建、更新、删除后主动清空缓存：

```python
def clear_items_cache():
    for key in redis_client.scan_iter("items:list:*"):
        redis_client.delete(key)
    redis_client.delete("items:list")
```

### 6. 缓存命中统计
```text
GET /cache/stats
```

接口会返回 Redis 商品缓存的命中/未命中次数：

```json
{"hits": 1, "misses": 2}
```

## 五、三个经典问题

### 1. 缓存穿透
- 问题：查询不存在的 key，每次都打到数据库
- 解决：缓存空值，或使用布隆过滤器

### 2. 缓存击穿
- 问题：热点 key 过期，大量请求同时打数据库
- 解决：互斥锁重建缓存，或逻辑过期

### 3. 缓存雪崩
- 问题：大量 key 同时过期，数据库压力骤增
- 解决：过期时间加随机值，或热点 key 永不过期
