# FastAPI基础
## 路由
什么是路由
```
路由是URL地址和处理函数之间的映射关系
```

```python
@app.get("/")
async def root():
    return {"message": "Hello World"}
```
app:FastAPI实例
get:请求方法
("/"):请求路径
async:异步
return {"message": "Hello World"}:响应结果

## 参数

- 路径参数
- 位置：URL路径的一部分
- 作用：指向唯一的、特定的资源
- 方法：GET
```python
@app.get("/book/{id}")
async def get_book(id: int):
    return {"id": id, "title": f"这是第{id}本书"}
```

查询参数
- 位置:URL?之后 k1=v1&k2=v2
- 作用：对资源集合机型过滤、排序、分页等操作
- 方法：GET
```python
from fastapi import Query
@app.get("/news/news_list")
async def get_new_list(
    skip: int = Query(0, description="跳过的记录数", lt=100), 
    limit: int = Query(10, description="返回的记录数")
):
    return {"skip": skip, "limit": limit}
```

请求体参数
- 位置：HTTP请求的消息体(body)中
- 作用：创建、更新资源 携带大量数据，如：JSON
- 方法:POST、PUT等
```python
from pydantic import BaseModel
class User(BaseModel):
    username: str
    password: str
@app.post("/register")
async def register(user: User):
    return user
```
请求体参数 - Field 校验
```python
from pydantic import BaseModel, Field
class User(BaseModel):
    username: str = Field(..., min_length=3, max_length=20, description="用户名")
    password: str = Field(..., min_length=6, max_length=100, description="密码")
    age: int = Field(18, ge=0, le=150, description="年龄")
    email: str | None = Field(None, pattern=r"^\S+@\S+\.\S+$", description="邮箱")

@app.post("/register")
async def register(user: User):
    return {"username": user.username, "age": user.age}
```
- `Field(...)` 表示必需字段，`Field(默认值)` 为可选字段
- `min_length`/`max_length`：字符串长度验证
- `ge`/`le`：数值范围验证（>= / <=）
- `pattern`：正则表达式验证
- `description`：生成 OpenAPI 文档说明

响应类型
- json格式
- html格式
- 文件格式

FastAPI 默认返回 JSON，但可以通过 Response 子类返回其他格式。
```python
from fastapi.responses import JSONResponse, HTMLResponse, FileResponse, RedirectResponse

@app.get("/json")
async def get_json():
    return JSONResponse({"msg": "这是JSON"})

@app.get("/html")
async def get_html():
    html = "<h1>Hello FastAPI</h1>"
    return HTMLResponse(html)

@app.get("/file")
async def get_file():
    return FileResponse("path/to/file.pdf")

@app.get("/redirect")
async def redirect():
    return RedirectResponse("/")
```
自定义状态码
```python
@app.post("/item", status_code=201)
async def create_item():
    return {"item": "created"}
```
- 默认状态码 200；POST 通常用 201 Created
- `status_code` 可传入 `fastapi.status.HTTP_201_CREATED` 等常量

自定义响应数据格式 - response_model
通过 response_model 控制返回数据的结构和类型，自动过滤和文档化：
```python
from pydantic import BaseModel

class ItemOut(BaseModel):
    id: int
    name: str
    price: float

@app.post("/items", response_model=ItemOut)
async def create_item(name: str, price: float):
    # 即使返回字典包含多余字段，response_model 也会过滤
    return {"id": 1, "name": name, "price": price, "secret": "不显示"}
```
- `response_model_exclude_unset=True`：只返回前端传入的字段
- `response_model_include={"id", "name"}`：只包含指定字段
- `response_model_exclude={"secret"}`：排除指定字段

异常响应处理
```python
from fastapi import HTTPException
from fastapi.responses import JSONResponse

# 直接抛出 HTTPException
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id <= 0:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"item_id": item_id}

# 自定义异常处理器
class CustomException(Exception):
    def __init__(self, name: str):
        self.name = name

@app.exception_handler(CustomException)
async def custom_handler(request, exc: CustomException):
    return JSONResponse(
        status_code=400,
        content={"error": f"自定义异常: {exc.name}"}
    )

@app.get("/custom")
async def custom_error():
    raise CustomException("出错了")
```
- `HTTPException` 是最常用的内置异常，会返回 JSON 错误信息
- `@app.exception_handler` 可以注册自定义异常处理函数
- 全局异常处理器会覆盖默认行为
