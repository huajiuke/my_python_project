# FastAPI进阶

## 中间件

### 什么是中间件
中间件是请求进入路由函数之前、响应返回客户端之前的一层处理逻辑，可以在不修改业务代码的情况下统一处理：
- 请求日志
- 耗时统计
- 权限校验
- 请求头处理
- 统一错误包装

### 执行流程
```text
客户端请求
  -> 中间件（请求进入前）
    -> 路由函数
  -> 中间件（响应返回前）
-> 客户端响应
```

### 内置 CORS 中间件
```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```
- `allow_origins`：允许跨域的前端地址
- `allow_methods`：允许的请求方法，`"*"` 表示全部
- `allow_headers`：允许的请求头

### 自定义中间件
```python
import time
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware

class LogMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        start = time.time()
        # 请求进入路由之前
        response = await call_next(request)
        # 响应返回客户端之前
        cost = round((time.time() - start) * 1000, 2)
        response.headers["X-Process-Time"] = str(cost)
        print(f"{request.method} {request.url.path} 耗时 {cost}ms")
        return response

app.add_middleware(LogMiddleware)
```
- `call_next(request)`：把请求交给下一个中间件或路由处理
- 中间件按添加顺序执行；自定义中间件建议写在 CORS 之后

## 依赖注入

### 什么是依赖注入
把路径操作函数需要用到的公共能力（数据库连接、认证、配置等）通过参数声明出来，由 FastAPI 自动创建并传入，不需要手动初始化。

### Depends 基础用法
```python
from fastapi import Depends

def get_current_user(token: str):
    # 模拟从 token 解析用户
    return {"username": "zhangsan"}

@app.get("/users/me")
async def read_user_me(user: dict = Depends(get_current_user)):
    return user
```
- 依赖函数可以像普通参数一样接收 Query、Header 等
- 路径操作函数通过 `Depends(...)` 声明依赖

### 类作为依赖
```python
class Pagination:
    def __init__(self, page: int = 1, size: int = 10):
        self.page = page
        self.size = size

@app.get("/news")
async def get_news(pagination: Pagination = Depends()):
    return {"page": pagination.page, "size": pagination.size}
```
类的 `__init__` 参数会由 FastAPI 自动解析，类似查询参数。

### 带 yield 的依赖
适合需要“用完释放资源”的场景，例如数据库连接：
```python
def get_db():
    db = connect_database()
    try:
        yield db
    finally:
        db.close()

@app.get("/items")
async def read_items(db=Depends(get_db)):
    return db.query_all()
```
- `yield` 前面的代码在请求前执行
- `finally` 里的代码在响应后执行，用来释放资源

### 依赖的依赖
```python
def get_user(db=Depends(get_db)):
    return db.find_user()

def require_login(user=Depends(get_user)):
    if user is None:
        raise HTTPException(status_code=401, detail="未登录")
    return user

@app.get("/profile")
async def profile(user=Depends(require_login)):
    return {"user": user}
```
依赖之间也可以互相嵌套，FastAPI 会自动处理调用顺序。

### 常见用途
- 数据库会话
- 登录认证 / 权限校验
- 公共查询参数（分页、排序）
- 配置对象

## APIRouter 路由模块化
项目变大后把不同业务的接口拆到独立文件中。

```python
# app/users.py
from fastapi import APIRouter

router = APIRouter(prefix="/users", tags=["用户"])

@router.get("/{user_id}")
async def get_user(user_id: int):
    return {"user_id": user_id}
```

```python
# main.py
from fastapi import FastAPI
from users import router as users_router

app = FastAPI()
app.include_router(users_router)
```
- `prefix`：给该路由下所有接口统一加前缀，如 `/users`
- `tags`：在 Swagger 文档中分组显示
- `include_router`：把子路由注册进主应用

## Header 与 Cookie
```python
from fastapi import Header, Cookie

@app.get("/headers")
async def read_headers(
    user_agent: str | None = Header(None),
    token: str | None = Header(None, alias="Authorization"),
    session_id: str | None = Cookie(None),
):
    return {
        "user_agent": user_agent,
        "token": token,
        "session_id": session_id,
    }
```
- Header 默认把下划线转成连字符，如 `user_agent` 对应 `user-agent`
- `alias` 用于匹配带 `-` 的原始请求头名

## 表单与文件上传
需要先安装：`pip install python-multipart`

```python
from fastapi import Form, File, UploadFile

@app.post("/upload")
async def upload(
    username: str = Form(...),
    file: UploadFile = File(...),
):
    content = await file.read()
    return {
        "username": username,
        "filename": file.filename,
        "size": len(content),
    }
```
- `Form`：读取 `application/x-www-form-urlencoded` 表单字段
- `File`：接收单个文件，`UploadFile` 类型还提供 `filename`、`content_type`
- 多个文件用 `list[UploadFile] = File(...)`

## 后台任务 BackgroundTasks
在返回响应后执行耗时操作，例如发邮件、写日志、清理临时文件。

```python
from fastapi import BackgroundTasks

def send_email(to: str):
    # 模拟发送邮件
    print(f"send email to {to}")

@app.post("/send")
async def send_notice(email: str, background_tasks: BackgroundTasks):
    background_tasks.add_task(send_email, email)
    return {"message": "已受理"}
```
- 后台任务在响应发送之后执行
- 适合不需要客户端等待的操作

## 静态文件
```python
from fastapi.staticfiles import StaticFiles

app.mount("/static", StaticFiles(directory="static"), name="static")
```
访问 `http://127.0.0.1:8000/static/xxx.png` 即可获取 `static` 目录下的文件。

## 测试
FastAPI 自带测试客户端，可以不用启动服务器直接测试接口。

```python
from fastapi.testclient import TestClient

client = TestClient(app)

def test_root():
    response = client.get("/")
    assert response.status_code == 200
    assert response.json() == {"message": "Hello World"}
```
- 测试函数中以 `test_` 开头，可配合 pytest 运行
- 测试完成后要释放 TestClient 资源：`with TestClient(app) as client:`
