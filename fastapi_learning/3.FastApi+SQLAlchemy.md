# FastAPI + SQLAlchemy 集成

## 本节目标
- 用 SQLAlchemy ORM 连接 SQLite
- 用 FastAPI 依赖注入管理 Session
- 实现 User / Item 两张表的 CRUD
- 启动时自动建表
- 给每个路由加 Swagger 注解

## 项目结构
```text
fastApiProject/
├── main.py            # FastAPI 入口：lifespan 建表、挂载路由
├── database.py        # Engine / SessionLocal / Base / get_db
├── models.py          # User、Item ORM 模型
├── schemas.py         # Pydantic 请求/响应模型
├── dependencies.py    # 分页、模拟登录等公共依赖
└── routers/
    ├── users.py       # 用户注册、列表、当前用户、按ID查询
    └── items.py       # 商品列表、创建、查询、更新、删除
```

## 1. database.py：数据库连接层
```python
from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, sessionmaker

SQLALCHEMY_DATABASE_URL = "sqlite:///./fastapi.db"

engine = create_engine(
    SQLALCHEMY_DATABASE_URL,
    connect_args={"check_same_thread": False},
)
SessionLocal = sessionmaker(bind=engine)


class Base(DeclarativeBase):
    pass


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```
- `engine`：负责真正连接数据库
- `SessionLocal`：会话工厂，用来创建 Session
- `Base`：所有 ORM 模型必须继承的基类
- `get_db()`：FastAPI 依赖，请求结束自动关闭 Session

## 2. models.py：ORM 模型
```python
from datetime import datetime
from typing import List, Optional

from sqlalchemy import DateTime, Float, ForeignKey, Integer, String
from sqlalchemy.orm import Mapped, mapped_column, relationship

from database import Base


class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    username: Mapped[str] = mapped_column(String(50), unique=True, index=True, nullable=False)
    password: Mapped[str] = mapped_column(String(100), nullable=False)
    age: Mapped[int] = mapped_column(Integer, default=18)
    email: Mapped[Optional[str]] = mapped_column(String(120), nullable=True)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.now)

    items: Mapped[List["Item"]] = relationship(back_populates="user")


class Item(Base):
    __tablename__ = "items"

    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String(50), nullable=False)
    price: Mapped[float] = mapped_column(Float, nullable=False)
    user_id: Mapped[int] = mapped_column(ForeignKey("users.id"), nullable=False)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.now)

    user: Mapped["User"] = relationship(back_populates="items")
```
- `Mapped[str]`：字段类型注解
- `mapped_column(...)`：数据库列定义
- `ForeignKey("users.id")`：数据库层外键约束
- `relationship`：ORM 层关系，不会在数据库里生成额外列

## 3. schemas.py：Pydantic 模型
```python
from datetime import datetime
from pydantic import BaseModel, Field


class UserRegister(BaseModel):
    username: str = Field(..., min_length=3, max_length=20)
    password: str = Field(..., min_length=6, max_length=100)
    age: int = Field(18, ge=0, le=150)
    email: str | None = None


class UserOut(BaseModel):
    id: int
    username: str
    age: int
    email: str | None = None
    created_at: datetime


class ItemCreate(BaseModel):
    name: str = Field(..., min_length=1, max_length=50)
    price: float = Field(..., ge=0)
    user_id: int


class ItemUpdate(BaseModel):
    name: str | None = Field(None, min_length=1, max_length=50)
    price: float | None = Field(None, ge=0)


class ItemOut(BaseModel):
    id: int
    name: str
    price: float
    user_id: int
    created_at: datetime
```
- 请求体模型负责校验输入
- 响应体模型负责过滤输出，例如 `UserOut` 不含 `password`
- `ItemUpdate` 全部字段可选，配合 `exclude_unset=True` 做部分更新

## 4. routers：CRUD 套路
### 创建
```python
db_item = Item(**item.model_dump())
db.add(db_item)
db.commit()
db.refresh(db_item)
```
- `add`：加入会话
- `commit`：提交事务
- `refresh`：刷新数据库生成的值，如 id、created_at

### 查询
```python
# 按主键查单个
item = db.get(Item, item_id)

# 按条件查单个
user = db.query(User).filter(User.username == name).first()

# 查列表 + 分页
items = db.query(Item).offset(offset).limit(size).all()
```

### 更新
```python
for field, value in payload.model_dump(exclude_unset=True).items():
    setattr(item, field, value)
db.commit()
db.refresh(item)
```

### 删除
```python
db.delete(item)
db.commit()
```

### db.get 和 db.query 的区别
- `db.get(Model, id)`：只按主键查单个对象
- `db.query(Model)`：构造查询，可加 filter / offset / limit / all

## 5. main.py：启动时建表
```python
from contextlib import asynccontextmanager

from database import Base, engine


@asynccontextmanager
async def lifespan(app: FastAPI):
    Base.metadata.create_all(bind=engine)
    yield


app = FastAPI(title="FastAPI 学习项目", lifespan=lifespan)
```
如果不建表，第一次请求会报 500：`no such table`。

```python

    "/items",
    response_model=list[ItemOut],
    summary="商品分页列表",
    description="使用分页依赖 Pagination，按 page 和 size 返回商品。",
)
async def list_items(...):
    """函数 docstring：给读代码的人看。"""
    ...
```
- `summary`：Swagger 里显示的标题
- `description`：Swagger 里的详细说明
- docstring：代码阅读时的说明

## 易错点
- `db = SessionLocal()` 必须带括号
- `Mapped/mapped_column/relationship` 从 `sqlalchemy.orm` 导入
- `Integer/String/Float/DateTime/ForeignKey` 从 `sqlalchemy` 导入
- `DateTime` 的 `T` 要大写
- `default=datetime.now` 不带括号
- `/users/me` 要写在 `/users/{user_id}` 前面
- 响应模型不要返回 password
- 密码目前是明文存储，第 7 周学习 JWT + 密码哈希后再升级
