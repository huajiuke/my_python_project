# Redis 常用操作实例

> 当前项目 Redis 地址：`redis://localhost:6379/0`
> 命令行用 `docker exec -it fastapiproject-redis-1 redis-cli`
> Python 用 `redis.Redis.from_url("redis://localhost:6379/0", decode_responses=True)`

## 一、Key 通用操作

### redis-cli
```bash
SET name zhangsan
GET name
EXISTS name
EXPIRE name 60
TTL name
TYPE name
DEL name
```

### Python
```python
redis_client.set("name", "zhangsan")
print(redis_client.get("name"))
print(redis_client.exists("name"))
redis_client.expire("name", 60)
print(redis_client.ttl("name"))
print(redis_client.type("name"))
redis_client.delete("name")
```

## 二、String：缓存和计数器

### redis-cli
```bash
SETEX code:138 300 123456
SETNX lock:order:1 1
INCR article:1:views
INCRBY article:1:views 10
MSET user:1 zhangsan user:2 lisi
MGET user:1 user:2
```

### Python
```python
redis_client.setex("code:138", 300, "123456")
redis_client.setnx("lock:order:1", 1)
redis_client.incr("article:1:views")
redis_client.incrby("article:1:views", 10)
redis_client.mset({"user:1": "zhangsan", "user:2": "lisi"})
print(redis_client.mget(["user:1", "user:2"]))
```

## 三、Hash：存储对象

### redis-cli
```bash
HSET user:1001 name zhangsan
HSET user:1001 age 20
HGET user:1001 name
HGETALL user:1001
HDEL user:1001 age
HEXISTS user:1001 name
HINCRBY user:1001 score 10
```

### Python
```python
redis_client.hset("user:1001", "name", "zhangsan")
redis_client.hset("user:1001", "age", 20)
print(redis_client.hget("user:1001", "name"))
print(redis_client.hgetall("user:1001"))
redis_client.hdel("user:1001", "age")
print(redis_client.hexists("user:1001", "name"))
redis_client.hincrby("user:1001", "score", 10)
```

输出：
```text
zhangsan
{"name": "zhangsan", "age": "20"}
True
```

## 四、List：队列和时间线

### redis-cli
```bash
LPUSH task_queue task1
RPUSH task_queue task2
LRANGE task_queue 0 -1
LPOP task_queue
LLEN task_queue
BLPOP task_queue 5
```

### Python
```python
redis_client.lpush("task_queue", "task1")
redis_client.rpush("task_queue", "task2")
print(redis_client.lrange("task_queue", 0, -1))
print(redis_client.lpop("task_queue"))
print(redis_client.llen("task_queue"))
print(redis_client.blpop("task_queue", timeout=5))
```

输出：
```text
["task1", "task2"]
task1
1
["task_queue", "task2"]
```

## 五、Set：去重和关系运算

### redis-cli
```bash
SADD tags python
SADD tags redis
SADD tags fastapi
SMEMBERS tags
SISMEMBER tags redis
SCARD tags
SINTER tags1 tags2
SUNION tags1 tags2
```

### Python
```python
redis_client.sadd("tags", "python", "redis", "fastapi")
print(redis_client.smembers("tags"))
print(redis_client.sismember("tags", "redis"))
print(redis_client.scard("tags"))

redis_client.sadd("tags1", "python", "redis")
redis_client.sadd("tags2", "redis", "mysql")
print(redis_client.sinter("tags1", "tags2"))
print(redis_client.sunion("tags1", "tags2"))
```

输出：
```text
{"python", "fastapi", "redis"}
True
3
{"redis"}
{"python", "mysql", "redis"}
```

## 六、ZSet：排行榜

### redis-cli
```bash
ZADD rank 90 user1
ZADD rank 80 user2
ZADD rank 70 user3
ZSCORE rank user1
ZREVRANGE rank 0 2
ZINCRBY rank 20 user2
ZREVRANK rank user2
```

### Python
```python
redis_client.zadd("rank", {"user1": 90, "user2": 80, "user3": 70})
print(redis_client.zscore("rank", "user1"))
print(redis_client.zrevrange("rank", 0, 2, withscores=True))
redis_client.zincrby("rank", 20, "user2")
print(redis_client.zrevrank("rank", "user2"))
```

输出：
```text
90.0
[("user1", 90.0), ("user2", 80.0), ("user3", 70.0)]
0
```

## 七、事务与 Pipeline

### redis-cli
```bash
MULTI
SET a 1
INCR b
EXEC
```

### Python
```python
pipe = redis_client.pipeline()
pipe.set("a", 1)
pipe.incr("b")
pipe.execute()
```

大量写入时使用 Pipeline 减少网络往返：
```python
pipe = redis_client.pipeline(transaction=False)
for i in range(100):
    pipe.set(f"key:{i}", i)
pipe.execute()
```

## 八、分布式锁

### Python
```python
is_locked = redis_client.set(
    "lock:order:1001",
    "1",
    nx=True,
    ex=30,
)
if is_locked:
    try:
        print("处理订单")
    finally:
        redis_client.delete("lock:order:1001")
```

`NX`：key 不存在才设置
`EX 30`：30 秒自动过期，防止死锁

## 九、发布订阅

### redis-cli
```bash
# 订阅端
SUBSCRIBE news

# 发布端
PUBLISH news "hello"
```

### Python
```python
# 发布
redis_client.publish("news", "hello")

# 订阅
pubsub = redis_client.pubsub()
pubsub.subscribe("news")
message = pubsub.get_message()
```

## 十、本项目中的 Redis 应用

### 商品分页缓存
```python
cache_key = f"items:list:{pagination.page}:{pagination.size}"
cached = redis_client.get(cache_key)
if cached is not None:
    return json.loads(cached)

items = db.query(Item).offset(offset).limit(size).all()
redis_client.setex(cache_key, 60, json.dumps(jsonable_encoder(items)))
return items
```

### 缓存失效
```python
def clear_items_cache():
    for key in redis_client.scan_iter("items:list:*"):
        redis_client.delete(key)
    redis_client.delete("items:list")
```

### 缓存命中统计
```python
redis_client.incr("stats:cache_hit")
redis_client.incr("stats:cache_miss")
```

## 十一、记忆口诀

- String：缓存、计数、锁
- Hash：对象、用户资料
- List：队列、时间线
- Set：去重、交集
- ZSet：排行榜、热点
- Pub/Sub：实时消息
- Pipeline：批量操作
- `EXPIRE/TTL`：控制缓存生命周期
