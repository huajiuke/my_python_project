# FastAPI JWT 认证完整流程

## 一、涉及文件
```text
fastApiProject/
├── security.py           # 密码哈希 + JWT 工具
├── schemas.py            # Token 响应模型
├── dependencies.py       # 登录解析、当前用户依赖
├── routers/
│   ├── auth.py           # POST /auth/login 登录接口
│   └── users.py          # 注册、/users/me
└── models.py             # User.password 存储 bcrypt 哈希
```

## 二、完整流程图
```text
1. 注册
客户端 -> POST /users/register
      -> hash_password(密码) 生成 bcrypt 哈希
      -> 哈希存入 User.password
      -> 返回 UserOut（不含 password）

2. 登录
客户端 -> POST /auth/login（表单 username/password）
      -> 按 username 查 User
      -> verify_password(明文密码, 数据库哈希)
      -> create_access_token(user.id) 签发 JWT
      -> 返回 Token

3. 访问受保护接口
客户端 -> Authorization: Bearer <token>
      -> oauth2_scheme 取出 token
      -> get_current_user 解码 token
      -> db.get(User, user_id) 查当前用户
      -> require_login 返回 User
      -> 路由拿到当前用户
```

## 三、每个函数的作用

### 1. security.py：安全工具
```python
SECRET_KEY = "dev-secret-change-me"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30
```
- `SECRET_KEY`：JWT 签名密钥，生产环境必须放到环境变量
- `ALGORITHM`：签名算法，这里用 HS256
- `ACCESS_TOKEN_EXPIRE_MINUTES`：token 有效期 30 分钟

```python
def hash_password(password: str) -> str:
    """注册时把明文密码转成 bcrypt 哈希字符串。"""
    password = bcrypt.hashpw(password.encode("utf-8"), bcrypt.gensalt())
    return password.decode("utf-8")
```
作用：密码不能明文入库，注册时调用。

```python
def verify_password(password: str, hashed_password: str) -> bool:
    """登录时校验明文密码和数据库里的哈希是否匹配。"""
    return bcrypt.checkpw(password.encode("utf-8"), hashed_password.encode("utf-8"))
```
作用：登录时调用，返回 True/False。

```python
def create_access_token(user_id: int) -> str:
    """根据用户 id 签发 JWT。"""
    expire = datetime.now(timezone.utc) + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    payload = {"sub": str(user_id), "exp": expire}
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)
```
作用：登录成功后生成 token，`sub` 存用户 id，`exp` 存过期时间。

```python
def decode_access_token(token: str) -> int:
    """解析 JWT，返回用户 id。"""
    payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
    return int(payload["sub"])
```
作用：每次受保护请求解析 token，验签 + 检查过期。

### 2. routers/auth.py：登录接口
```python
@router.post("/login", response_model=Token)
async def login(
    form_data: OAuth2PasswordRequestForm = Depends(),
    db: Session = Depends(get_db),
):
    user = db.query(User).filter(User.username == form_data.username).first()
    if user is None or not verify_password(form_data.password, user.password):
        raise HTTPException(status_code=401, detail="用户名或密码错误")
    token = create_access_token(user.id)
    return Token(access_token=token)
```
作用：
1. 按用户名查用户
2. 用户不存在或密码错误 -> 401
3. 密码正确 -> 签发 token

### 3. dependencies.py：认证依赖
```python
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="auth/login")
```
作用：告诉 FastAPI“受保护接口从 Authorization 头拿 Bearer token”，并在 Swagger 里生成锁图标。

```python
def get_current_user(
    token: str = Depends(oauth2_scheme),
    db: Session = Depends(get_db),
) -> User:
    try:
        user_id = decode_access_token(token)
    except (jwt.PyJWTError, KeyError, TypeError, ValueError):
        raise HTTPException(status_code=401, detail="无效的认证凭证")
    user = db.get(User, user_id)
    if user is None:
        raise HTTPException(status_code=401, detail="用户不存在")
    return user
```
作用：
1. 取出 token
2. 解码失败 -> 401
3. 按 user_id 查用户
4. 用户不存在 -> 401
5. 返回当前 User 对象

```python
def require_login(user: User = Depends(get_current_user)):
    return user
```
作用：给路由用的快捷依赖，自动执行 `get_current_user`。

### 4. routers/users.py：注册与当前用户
```python
password_hash = hash_password(user.password)
db_user = User(
    username=user.username,
    password=password_hash,
    age=user.age,
    email=user.email,
)
```
作用：注册时先把密码哈希，再写入数据库。

```python
@router.get("/me", response_model=UserOut)
async def read_me(current: User = Depends(require_login)):
    return current
```
作用：受保护接口，`require_login` 解析出当前用户后直接返回。

### 5. schemas.py：Token 响应模型
```python
class Token(BaseModel):
    access_token: str
    token_type: str = "bearer"
```
作用：规定登录接口返回 `access_token` 和 `token_type`。

## 四、请求示例
```text
注册
POST http://127.0.0.1:8080/users/register
Content-Type: application/json

{"username": "authuser", "password": "abc123", "age": 20, "email": "authuser@example.com"}

登录
POST http://127.0.0.1:8080/auth/login
Content-Type: application/x-www-form-urlencoded

username=authuser&password=abc123

访问当前用户
GET http://127.0.0.1:8080/users/me
Authorization: Bearer <access_token>
```

## 五、安全要点
- `SECRET_KEY` 生产环境放环境变量，不能写死在代码里
- JWT 必须设置 `exp` 过期时间
- payload 只是 Base64Url 编码，不能放密码等敏感信息
- 生产环境必须使用 HTTPS
- token 放 Authorization 头，不要放 URL

## 六、易错点
- `verify_password(明文, 哈希)` 两个参数顺序不能写反
- `db.query(User).filter(User.username == 用户名)` 条件不能漏
- `/users/me` 必须放在 `/users/{user_id}` 前面
- 旧数据里明文密码的用户，改成 bcrypt 后登录会失败，需要重新注册
- token 过期后客户端需要重新登录
