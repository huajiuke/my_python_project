# uuid 唯一标识

> 上级：[[01-Python基础/01.02-工程实践/01.02.03-代码组织/01.02.03-代码组织|01.02.03-代码组织]]

```python
import uuid

# 生成 32 位十六进制 ID
uid = uuid.uuid4().hex         # "a1b2c3d4e5f6..."

# 取前 8 位做短 ID
short_id = uuid.uuid4().hex[:8]  # "a1b2c3d4"
```

## 自己试试

```python
import uuid

class User:
    def __init__(self, name):
        self.id = uuid.uuid4().hex[:8]
        self.name = name

u1 = User("张三")
u2 = User("李四")
print(u1.id, u2.id)  # 各不相同
```
