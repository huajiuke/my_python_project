# if __name__ == '__main__' 入口惯用法

> 上级：[[01-Python基础/01.02-工程实践/01.02.03-代码组织/01.02.03-代码组织|01.02.03-代码组织]]

## 是什么

只有直接运行这个文件时才执行，被别的文件 import 时不执行。

## 项目中的例子

```python
if __name__ == "__main__":
    main()
```

## 为什么这么做

```python
# utils.py
def add(a, b):
    return a + b

# 如果不加 if 判断，别人 import utils 时会直接打印这句话
print("utils 被加载了")

# 正确的做法
if __name__ == "__main__":
    print("只有当 python utils.py 时才执行")
```
