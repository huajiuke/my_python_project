## 为什么用

项目之间依赖隔离，互不冲突。

## 基本操作

```bash
python -m venv venv
venv\Scripts\activate    # Windows
source venv/bin/activate # macOS/Linux
deactivate
```

## requirements.txt

```bash
pip freeze > requirements.txt
pip install -r requirements.txt
```

记得把 `venv/` 加到 `.gitignore`。
