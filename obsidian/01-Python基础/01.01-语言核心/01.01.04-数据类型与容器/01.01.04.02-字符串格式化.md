## f-string（Python 3.6+）

```python
name = "张三"
age = 25

# 直接嵌入变量
print(f"姓名: {name}, 年龄: {age}")

# 表达式
print(f"明年 {age + 1} 岁")

# 调用方法
print(f"大写: {name.upper()}")
```

## .format()

```python
# 项目中使用
header = "待办任务（{}个）".format(len(items))
print("  [{}] {}".format(task.id[:6], task.title))

# 位置参数
print("{} 今年 {} 岁".format("张三", 25))

# 按位置索引
print("{1} 是 {0} 的学生".format("老师", "张三"))

# 命名参数
print("{name} 今年 {age} 岁".format(name="张三", age=25))
```
