## 是什么

按需生成值，用 `yield` 代替 `return`。

## 为什么用

- 省内存（处理大量数据时）
- 惰性计算

## 例子

```python
def count_up_to(n):
    i = 1
    while i <= n:
        yield i
        i += 1

for num in count_up_to(5):
    print(num)
```

## 生成器表达式

```python
squares = (x * x for x in range(10))  # 生成器
squares_list = [x * x for x in range(10)]  # 列表
```

## 应用场景：读大文件

```python
def read_lines(filepath):
    with open(filepath, "r", encoding="utf-8") as f:
        for line in f:
            yield line.strip()
```
