## 是什么

实现了 `__iter__` 和 `__next__` 方法的对象。

## 关系

可迭代对象 -> __iter__() -> 迭代器 -> __next__() -> 依次取值

## 自定义迭代器

```python
class CountDown:
    def __init__(self, start):
        self.current = start
    def __iter__(self):
        return self
    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

for n in CountDown(3):
    print(n)
```

## 要点

- 生成器就是迭代器的一种
- for 循环底层就是在调 __next__()
