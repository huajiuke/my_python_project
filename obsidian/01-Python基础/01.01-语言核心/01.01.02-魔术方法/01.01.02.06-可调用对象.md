## `__call__(self, ...)`

使对象可以像函数一样被调用。

```python
class Counter:
    def __init__(self):
        self.count = 0

    def __call__(self):
        self.count += 1
        return self.count

c = Counter()
print(c())  # 1  相当于 c.__call__()
print(c())  # 2
print(c())  # 3
```

**应用场景**：装饰器、策略模式、带状态的函数替代品。
