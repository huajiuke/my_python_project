## 是什么

把有限的几个选项定义成类型，而不是用字符串到处写死。

## 项目中的例子

```python
from enum import Enum

class Priority(Enum):
    LOW = "low"
    MEDIUM = "medium"
    HIGH = "high"
    URGENT = "urgent"

class TaskStatus(Enum):
    PENDING = "pending"
    COMPLETED = "completed"

# 使用
p = Priority.HIGH
print(p.value)       # "high"
print(p.name)        # "HIGH"

# 从字符串还原
p2 = Priority("medium")
print(p2)            # Priority.MEDIUM
```

## 不用枚举的坏处

```python
# 到处写字符串，容易写错
if task.priority == "hight":   # 拼写错误，不会报错
    do_something()

# 改用枚举，写错就报错
if task.priority == Priority.HIGHT:  # NameError，立即发现
    do_something()
```

