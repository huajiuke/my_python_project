# AsyncSession 与 async_sessionmaker

> 上级：[[02-数据库/02.05-异步SQLAlchemy/02.05.01-核心概念/02.05.01-核心概念|02.05.01-核心概念]]

`AsyncSession` 是异步版的 Session，所有数据库操作都要 `await`。

## 创建会话工厂

```python
from sqlalchemy.ext.asyncio import async_sessionmaker, create_async_engine

engine = create_async_engine("sqlite+aiosqlite:///./async.db")
AsyncSessionLocal = async_sessionmaker(engine, expire_on_commit=False)
```

`expire_on_commit=False` 是异步推荐配置：提交后不自动过期属性，避免下一次访问属性时触发隐式同步 IO。

## 使用 AsyncSession

```python
async with AsyncSessionLocal() as session:
    user = await session.get(User, 1)
    result = await session.execute(select(User).where(User.age >= 18))
    users = result.scalars().all()
    await session.commit()
```

- `session.get()`：按主键查单个对象，需要 await
- `session.execute()`：执行 select/insert/update/delete，需要 await
- `result.scalars()`：取标量结果
- 每个请求或任务创建自己的 session，用完关闭

## 与同步 Session 的对应

| 同步 | 异步 |
|------|------|
| `Session(engine)` | `AsyncSession(engine)` |
| `sessionmaker(bind=engine)` | `async_sessionmaker(engine)` |
| `session.execute(stmt)` | `await session.execute(stmt)` |
| `session.commit()` | `await session.commit()` |
| `session.refresh(obj)` | `await session.refresh(obj)` |
