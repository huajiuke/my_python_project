# 异步引擎 create_async_engine

> 上级：[[02-数据库/02.05-异步SQLAlchemy/02.05.01-核心概念/02.05.01-核心概念|02.05.01-核心概念]]

SQLAlchemy 2.0 用 `sqlalchemy.ext.asyncio` 提供原生异步支持，异步入口是 `create_async_engine`。

## 创建异步引擎

```python
from sqlalchemy.ext.asyncio import create_async_engine

engine = create_async_engine(
    "sqlite+aiosqlite:///./async.db",
    echo=True,
)
```

- `create_async_engine` 返回 `AsyncEngine`，不能直接给同步 `Session` 用
- URL 里的驱动协议决定异步驱动：
  - SQLite：`sqlite+aiosqlite`
  - PostgreSQL：`postgresql+asyncpg`
  - MySQL：`mysql+aiomysql` 或 `mysql+asyncmy`
- 需要先安装对应驱动：`pip install aiosqlite asyncpg aiomysql`

## 异步连接与建表

```python
async with engine.begin() as conn:
    await conn.run_sync(Base.metadata.create_all)
```

`engine.begin()` 返回异步事务上下文；`run_sync` 把同步操作放到后台线程执行。

## 关闭引擎

```python
await engine.dispose()
```
