# 异步事务与会话管理

## 自动事务：engine.begin()

```python
async with engine.begin() as conn:
    await conn.execute(text("UPDATE users SET age = age + 1"))
# 正常结束自动 commit，异常自动 rollback
```

## 会话内事务

```python
async with AsyncSessionLocal() as session:
    async with session.begin():
        session.add(User(username="alice"))
    # 退出 begin 块时 commit
```

也可以手动管理：

```python
session = AsyncSessionLocal()
try:
    user = User(username="alice")
    session.add(user)
    await session.commit()
except Exception:
    await session.rollback()
    raise
finally:
    await session.close()
```

## 注意事项

- 每个请求/任务创建独立 session，避免跨任务复用
- 长时间持有 session 会占用连接池
- 异步上下文管理器仍保证 close
