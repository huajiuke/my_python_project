## 批量插入

少量数据用 `add_all`：

```python
session.add_all([User(username=f"user{i}") for i in range(100)])
await session.commit()
```

大量数据分批提交，避免单事务过大：

```python
for i in range(0, 10000, 500):
    session.add_all([
        User(username=f"user{j}") for j in range(i, i + 500)
    ])
    await session.commit()
```

## 流式查询

结果集很大时用 `stream` 逐批读取：

```python
from sqlalchemy import select

stmt = select(User).execution_options(yield_per=200)
result = await session.stream(stmt)
async for row in result:
    print(row[0].username)
await result.close()
```

## 分页

```python
users = (await session.execute(
    select(User).order_by(User.id).offset(20).limit(10)
)).scalars().all()
```
