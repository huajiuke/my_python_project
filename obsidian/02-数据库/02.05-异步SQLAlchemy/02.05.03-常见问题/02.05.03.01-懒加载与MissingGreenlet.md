# 懒加载与 MissingGreenlet

> 上级：[[02-数据库/02.05-异步SQLAlchemy/02.05.03-常见问题/02.05.03-常见问题|02.05.03-常见问题]]

## 问题

异步 Session 内访问未加载的 relationship 会报 `MissingGreenlet`：

```python
async with AsyncSessionLocal() as session:
    user = await session.get(User, 1)
    print(user.posts)  # MissingGreenlet: greenlet_spawn has not been called
```

原因：异步环境不能执行隐式同步 IO，懒加载需要发 SQL，但当前没有可用的同步上下文。

## 解决方法

### 1. 预加载（推荐）

```python
from sqlalchemy.orm import selectinload

stmt = select(User).options(selectinload(User.posts))
user = (await session.execute(stmt)).scalar_one()
print(user.posts)  # 已加载
```

### 2. 手动 refresh

```python
user = await session.get(User, 1)
await session.refresh(user, ["posts"])
print(user.posts)
```

### 3. AsyncAttrs + await

模型继承 `AsyncAttrs` 后：

```python
posts = await user.posts
```

## 经验

- 一次查询尽量把要用到的关系都预加载
- 会话关闭后不要访问懒加载属性
- 列表结果先转成普通列表再返回
