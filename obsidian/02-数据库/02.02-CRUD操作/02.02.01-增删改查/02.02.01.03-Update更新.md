```python
# 方式一：查到对象，改属性，提交
user = session.query(User).filter(User.id == 1).first()
user.username = "new_name"
session.commit()

# 方式二：直接更新（一条 SQL）
session.query(User).filter(User.id == 1).update({"username": "new_name"})
session.commit()
```
