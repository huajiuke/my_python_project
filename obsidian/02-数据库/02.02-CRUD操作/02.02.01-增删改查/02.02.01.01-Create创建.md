```python
user = User(username="alice")
session.add(user)       # 加入会话
session.commit()        # 提交事务，写入数据库
# 此时 user.id 自动有了值
```

批量添加：

```python
users = [User(username="a"), User(username="b")]
session.add_all(users)
session.commit()
```
