# 异步联查

> 上级：[[02-数据库/02.02-CRUD操作/02.02.03-联表查询/02.02.03-联表查询|02.02.03-联表查询]]

异步 SQLAlchemy 的 join 写法和同步完全一致，只是执行时 await：

```python
stmt = select(User).join(Article).where(Article.title.contains("Python"))
result = await session.execute(stmt)
users = result.scalars().all()
```

## 聚合联查

```python
stmt = (
    select(User.username, func.count(Article.id))
    .outerjoin(Article)
    .group_by(User.id)
)
rows = (await session.execute(stmt)).all()
```

## 异步注意事项

- 联查本身没有额外限制
- 关联对象不要依赖懒加载，用 selectinload 预加载
- 大结果集用 `await session.stream(stmt)`
