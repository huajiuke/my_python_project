# outerjoin 与聚合联查

> 上级：[[02-数据库/02.02-CRUD操作/02.02.03-联表查询/02.02.03-联表查询|02.02.03-联表查询]]

## 左外连接

```python
stmt = select(User).outerjoin(Article)
users = session.execute(stmt).scalars().all()
# LEFT OUTER JOIN，没有文章的用户也会保留
```

## 联表聚合

```python
from sqlalchemy import func

stmt = (
    select(User.username, func.count(Article.id).label("article_count"))
    .outerjoin(Article)
    .group_by(User.id)
    .order_by(func.count(Article.id).desc())
)
rows = session.execute(stmt).all()
```

## 联表过滤

```python
stmt = (
    select(User)
    .join(Article)
    .where(Article.title.contains("Python"))
)
```

## 选 outerjoin 还是 join

- 需要保留“无关联行”：outerjoin
- 只关心有关联的数据：join
- 聚合计数用 outerjoin 时，无文章的用户统计为 0 而不是被过滤掉
