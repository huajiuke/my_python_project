# aliased 同表多次 join

> 上级：[[02-数据库/02.02-CRUD操作/02.02.03-联表查询/02.02.03-联表查询|02.02.03-联表查询]]

## 问题

同一张表要 join 两次时，直接写会冲突，需要用 `aliased` 创建别名。

## 示例：订单的作者和审核人都是用户

```python
from sqlalchemy.orm import aliased

author = aliased(User)
reviewer = aliased(User)

stmt = (
    select(Order)
    .join(author, Order.author_id == author.id)
    .join(reviewer, Order.reviewer_id == reviewer.id)
)
orders = session.execute(stmt).scalars().all()
```

## 自连接（同一张表内上下级）

```python
manager = aliased(User)
stmt = (
    select(User)
    .join(manager, User.manager_id == manager.id)
    .where(manager.username == "boss")
)
```

## 要点

- aliased 相当于 SQL 里的表别名
- 每次需要不同角色/条件时创建一个新别名
- 结果实体仍是原模型
