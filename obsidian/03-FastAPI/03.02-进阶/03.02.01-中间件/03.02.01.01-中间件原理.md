## 什么是中间件
中间件是请求进入路由函数之前、响应返回客户端之前的一层处理逻辑，可以在不修改业务代码的情况下统一处理：
- 请求日志
- 耗时统计
- 权限校验
- 请求头处理
- 统一错误包装

## 执行流程
```text
客户端请求
  -> 中间件（请求进入前）
    -> 路由函数
  -> 中间件（响应返回前）
-> 客户端响应
```

## 内置 CORS 中间件
```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```
- `allow_origins`：允许跨域的前端地址
- `allow_methods`：允许的请求方法，`"*"` 表示全部
- `allow_headers`：允许的请求头

## 自定义中间件
```python
import time
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware

class LogMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        start = time.time()
        # 请求进入路由之前
        response = await call_next(request)
        # 响应返回客户端之前
        cost = round((time.time() - start) * 1000, 2)
        response.headers["X-Process-Time"] = str(cost)
        print(f"{request.method} {request.url.path} 耗时 {cost}ms")
        return response

app.add_middleware(LogMiddleware)
```
- `call_next(request)`：把请求交给下一个中间件或路由处理
- 中间件按添加顺序执行；自定义中间件建议写在 CORS 之后
