# 测试 TestClient

> 上级：[[03-FastAPI/03.02-进阶/03.02.04-高级功能/03.02.04-高级功能|03.02.04-高级功能]]

FastAPI 自带测试客户端，可以不用启动服务器直接测试接口。

```python
from fastapi.testclient import TestClient

client = TestClient(app)

def test_root():
    response = client.get("/")
    assert response.status_code == 200
    assert response.json() == {"message": "Hello World"}
```
- 测试函数中以 `test_` 开头，可配合 pytest 运行
- 测试完成后要释放 TestClient 资源：`with TestClient(app) as client:`
