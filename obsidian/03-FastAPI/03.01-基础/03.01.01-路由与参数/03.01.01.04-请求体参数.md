# 请求体参数

> 上级：[[03-FastAPI/03.01-基础/03.01.01-路由与参数/03.01.01-路由与参数|03.01.01-路由与参数]]

- 位置：HTTP请求的消息体(body)中
- 作用：创建、更新资源 携带大量数据，如：JSON
- 方法:POST、PUT等
```python
from pydantic import BaseModel
class User(BaseModel):
    username: str
    password: str
@app.post("/register")
async def register(user: User):
    return user
```
