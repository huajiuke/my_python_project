# 练习 7：自定义校验

> 上级：[[03-FastAPI/03.03-实战项目/03.03.03-Pydantic练习/03.03.03-Pydantic练习|03.03.03-Pydantic练习]]

```python
from pydantic import BaseModel, Field, field_validator

class UserRegister(BaseModel):
    username: str = Field(..., min_length=3, max_length=20)
    password: str = Field(..., min_length=6)

    @field_validator("password")
    @classmethod
    def check_password(cls, value: str) -> str:
        # TODO: 密码必须包含至少一个数字，否则 raise ValueError
        for c in value:
            if c.isdigit():
                return value
        raise ValueError
```

验证：
```python
UserRegister(username="zhangsan", password="abc123")  # 应该通过
UserRegister(username="zhangsan", password="abcdef")  # 应该报错
```
