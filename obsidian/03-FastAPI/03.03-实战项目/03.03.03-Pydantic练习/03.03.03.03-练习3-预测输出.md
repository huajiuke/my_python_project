阅读下面代码，回答两个问题：
```python
class UserCreate(BaseModel):
    username: str = Field(..., min_length=3, max_length=20)
    password: str = Field(..., min_length=6)
    age: int = Field(18, ge=0, le=150)
    email: str | None = None

user = UserCreate(username="zhangsan", password="123456", age="25")
print(type(user.age))
print(user.model_dump())
```
问题：
1. `age` 最终是什么类型？
    int类型
2. `model_dump()` 会输出什么？
    {"username": "zhangsan", "password": "123456", "age": "25", "email": "None"}
