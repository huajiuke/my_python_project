定义 `UserCreate` 模型：
- `username`：必填，3-20 个字符
- `password`：必填，至少 6 位
- `age`：可选，默认 18，范围 0-150
- `email`：可选，默认 None

```python
from pydantic import BaseModel, Field

class UserCreate(BaseModel):
    username: str = Field(..., min_length=3, max_length=20)  # TODO
    password: str = Field(..., min_length=6)  # TODO
    age: int = Field(18, ge=0, le=150)  # TODO
    email: str | None = None  # TODO
```
