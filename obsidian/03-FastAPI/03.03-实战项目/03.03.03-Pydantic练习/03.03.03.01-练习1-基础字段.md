定义 `Book` 模型，要求：
- `title`：必填，3-50 个字符
- `price`：必填，不能小于 0
- `tags`：默认空列表

```python
from pydantic import BaseModel, Field

class Book(BaseModel):
    title: str = Field(..., min_length=3, max_length=50)  # TODO: 补校验
    price: float = Field(..., ge=0)  # TODO: 补校验
    tags: list[str] = []  # 已给，不需要改
```

验证：
```python
Book(title="Python入门", price=59.9)                 # 应该通过
Book(title="ab", price=59.9)                         # 应该报错
Book(title="Python入门", price=-1)                   # 应该报错
```
