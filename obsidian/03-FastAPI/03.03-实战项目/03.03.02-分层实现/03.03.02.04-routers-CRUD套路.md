## 创建
```python
db_item = Item(**item.model_dump())
db.add(db_item)
db.commit()
db.refresh(db_item)
```
- `add`：加入会话
- `commit`：提交事务
- `refresh`：刷新数据库生成的值，如 id、created_at

## 查询
```python
# 按主键查单个
item = db.get(Item, item_id)

# 按条件查单个
user = db.query(User).filter(User.username == name).first()

# 查列表 + 分页
items = db.query(Item).offset(offset).limit(size).all()
```

## 更新
```python
for field, value in payload.model_dump(exclude_unset=True).items():
    setattr(item, field, value)
db.commit()
db.refresh(item)
```

## 删除
```python
db.delete(item)
db.commit()
```

## db.get 和 db.query 的区别
- `db.get(Model, id)`：只按主键查单个对象
- `db.query(Model)`：构造查询，可加 filter / offset / limit / all
