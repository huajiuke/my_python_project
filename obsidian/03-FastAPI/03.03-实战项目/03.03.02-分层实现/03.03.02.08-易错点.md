# 易错点

> 上级：[[03-FastAPI/03.03-实战项目/03.03.02-分层实现/03.03.02-分层实现|03.03.02-分层实现]]

- `db = SessionLocal()` 必须带括号
- `Mapped/mapped_column/relationship` 从 `sqlalchemy.orm` 导入
- `Integer/String/Float/DateTime/ForeignKey` 从 `sqlalchemy` 导入
- `DateTime` 的 `T` 要大写
- `default=datetime.now` 不带括号
- `/users/me` 要写在 `/users/{user_id}` 前面
- 响应模型不要返回 password
- 密码目前是明文存储，第 7 周学习 JWT + 密码哈希后再升级
