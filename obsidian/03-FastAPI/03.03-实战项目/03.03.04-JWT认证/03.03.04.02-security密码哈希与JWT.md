```python
SECRET_KEY = "dev-secret-change-me"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30
```
- `SECRET_KEY`：JWT 签名密钥，生产环境必须放到环境变量
- `ALGORITHM`：签名算法，这里用 HS256
- `ACCESS_TOKEN_EXPIRE_MINUTES`：token 有效期 30 分钟

```python
def hash_password(password: str) -> str:
    """注册时把明文密码转成 bcrypt 哈希字符串。"""
    password = bcrypt.hashpw(password.encode("utf-8"), bcrypt.gensalt())
    return password.decode("utf-8")
```
作用：密码不能明文入库，注册时调用。

```python
def verify_password(password: str, hashed_password: str) -> bool:
    """登录时校验明文密码和数据库里的哈希是否匹配。"""
    return bcrypt.checkpw(password.encode("utf-8"), hashed_password.encode("utf-8"))
```
作用：登录时调用，返回 True/False。

```python
def create_access_token(user_id: int) -> str:
    """根据用户 id 签发 JWT。"""
    expire = datetime.now(timezone.utc) + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    payload = {"sub": str(user_id), "exp": expire}
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)
```
作用：登录成功后生成 token，`sub` 存用户 id，`exp` 存过期时间。

```python
def decode_access_token(token: str) -> int:
    """解析 JWT，返回用户 id。"""
    payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
    return int(payload["sub"])
```
作用：每次受保护请求解析 token，验签 + 检查过期。
