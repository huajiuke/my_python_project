## 七、事务与 Pipeline

## redis-cli
```bash
MULTI
SET a 1
INCR b
EXEC
```

## Python
```python
pipe = redis_client.pipeline()
pipe.set("a", 1)
pipe.incr("b")
pipe.execute()
```

大量写入时使用 Pipeline 减少网络往返：
```python
pipe = redis_client.pipeline(transaction=False)
for i in range(100):
    pipe.set(f"key:{i}", i)
pipe.execute()
```
