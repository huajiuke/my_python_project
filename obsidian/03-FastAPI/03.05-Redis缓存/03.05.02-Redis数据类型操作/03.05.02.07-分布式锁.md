## 八、分布式锁

## Python
```python
is_locked = redis_client.set(
    "lock:order:1001",
    "1",
    nx=True,
    ex=30,
)
if is_locked:
    try:
        print("处理订单")
    finally:
        redis_client.delete("lock:order:1001")
```

`NX`：key 不存在才设置
`EX 30`：30 秒自动过期，防止死锁
