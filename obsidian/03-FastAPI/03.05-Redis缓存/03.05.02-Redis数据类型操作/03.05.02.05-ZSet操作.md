## 六、ZSet：排行榜

## redis-cli
```bash
ZADD rank 90 user1
ZADD rank 80 user2
ZADD rank 70 user3
ZSCORE rank user1
ZREVRANGE rank 0 2
ZINCRBY rank 20 user2
ZREVRANK rank user2
```

## Python
```python
redis_client.zadd("rank", {"user1": 90, "user2": 80, "user3": 70})
print(redis_client.zscore("rank", "user1"))
print(redis_client.zrevrange("rank", 0, 2, withscores=True))
redis_client.zincrby("rank", 20, "user2")
print(redis_client.zrevrank("rank", "user2"))
```

输出：
```text
90.0
[("user1", 90.0), ("user2", 80.0), ("user3", 70.0)]
0
```
