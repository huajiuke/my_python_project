# 项目接入 Redis

> 上级：[[03-FastAPI/03.05-Redis缓存/03.05.01-Redis基础/03.05.01-Redis基础|03.05.01-Redis基础]]

## 1. docker-compose.yml 增加 Redis
```yaml
redis:
  image: redis:7
  restart: unless-stopped
  ports:
    - "6379:6379"
  healthcheck:
    test: ["CMD", "redis-cli", "ping"]
    interval: 5s
    timeout: 5s
    retries: 10
```


## 2. 配置 REDIS_URL
```python
REDIS_URL = os.getenv("REDIS_URL", "redis://localhost:6379/0")
```

Docker 环境中：
```text
REDIS_URL=redis://redis:6379/0
```


## 3. Redis 客户端
```python
import redis

redis_client = redis.Redis.from_url(REDIS_URL, decode_responses=True)
```


## 4. 缓存接口
```text
GET /items/cached
```
- 先查 Redis
- 未命中再查 MySQL
- 结果写入 Redis，TTL 60 秒


## 六、验证
```bash
docker compose up --build -d

# 访问缓存接口
curl http://127.0.0.1:8000/items/cached

# 查看 Redis 缓存
docker exec fastapiproject-redis-1 redis-cli GET items:list

# 查看过期时间
docker exec fastapiproject-redis-1 redis-cli TTL items:list
```

验证结果：
```text
fastapiproject-redis-1  Up (healthy)
GET /items/cached -> []
Redis key items:list 已写入，TTL 生效
```
