## 三、缓存模式 Cache Aside
```text
读请求：
1. 查 Redis
2. 命中 -> 直接返回
3. 未命中 -> 查 MySQL
4. 写入 Redis（带过期时间）
5. 返回结果

写请求：
1. 更新 MySQL
2. 删除 Redis 缓存
```

项目中的示例：
```python
cache_key = "items:list"
cached = redis_client.get(cache_key)
if cached is not None:
    return json.loads(cached)

items = db.query(Item).all()
redis_client.setex(cache_key, 60, json.dumps(jsonable_encoder(items)))
return items
```
