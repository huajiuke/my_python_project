## 6. 缓存命中统计
```text
GET /cache/stats
```

接口会返回 Redis 商品缓存的命中/未命中次数：

```json
{"hits": 1, "misses": 2}
```


## 缓存命中统计
```python
redis_client.incr("stats:cache_hit")
redis_client.incr("stats:cache_miss")
```
